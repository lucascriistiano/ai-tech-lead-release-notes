New Features

Idempotency Key Support

Adds support for the Idempotency-Key header in POST /transactions to prevent double charges on network failures.

Implements a system-wide dark mode based on user preference using Tailwind classes.

Two-Factor Authentication (2FA)

Adds TOTP support (Google/Microsoft Authenticator) for user login.

Export Transactions to PDF

New endpoint to generate PDF statements for merchants.

Slack Webhooks for Payments

Allows merchants to receive Slack notifications on successful payments.

Biometric Login Support

React Native bridge for FaceID/TouchID.

Automatic PIX Support

Fraud Control Dashboard

Enables admins to manually block suspicious IPs, reducing chargeback risks.

Multi-Currency Support (USD/EUR)

Expands market reach to international merchants.

Mobile Biometric Login

Improves user retention and login speed on mobile apps.

Bug Fixes

Resolve Deadlock in Wallet Transfer

Fixes a critical race condition where simultaneous transfers could lock the row indefinitely. Applied SELECT FOR UPDATE SKIP LOCKED.

Correct Decimal Rounding on Invoice PDF

Invoices were showing 10.999 instead of 11.00. Fixed formatting utility.

Patch SQL Injection Vulnerability in Search

Sanitized inputs on the global search bar. Critical fix.

Handle Null Phone Numbers in Webhook Payload

Prevents 500 error when phone number is missing in legacy payloads.

Fix Crash on Startup iOS 17

Updated splash screen library to support newer iOS versions.

Alignment Issue on Settings Page

Fixed 2px misalignment in the submit button.

Error 500 When Exporting Large CSV

Implemented streaming response.

SQL Injection Vulnerability in Search

Applied parameter binding.

App Crashes on Opening in iOS 17

Resolved through library upgrade.

Duplicate Charges During Network Fluctuations

Implemented idempotency logic.
