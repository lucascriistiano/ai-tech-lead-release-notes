Risks & Recommendations

The deployment includes critical security patches for SQL Injection vulnerabilities and breaking changes with the deprecation of XML API endpoints.

  • Monitorar o desempenho do banco de dados e o comportamento de bloqueio após a implantação para garantir que a correção de deadlock seja eficaz.
  • Verificar se todos os clientes da API migraram para endpoints JSON para evitar interrupções no serviço.
  • Realizar varreduras de segurança para confirmar que as vulnerabilidades de SQL Injection estão totalmente mitigadas.
