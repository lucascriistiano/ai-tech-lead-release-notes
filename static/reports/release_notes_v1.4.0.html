New Features

feat(api): Implement Idempotency Key support

Adds support for Idempotency-Key header in POST /transactions to prevent double charges on network failures.

feat(dashboard): Dark Mode Toggle

Implements system-wide dark mode based on user preference using Tailwind classes.

feat(auth): 2FA with Authenticator App

Adds TOTP support (Google/Microsoft Authenticator) for user login.

feat(reports): Export transactions to PDF

New endpoint to generate PDF statements for merchants.

feat(integrations): Slack Webhooks for payments

Allows merchants to receive Slack notifications on successful payments.

feat(mobile): Biometric login support

React Native bridge for FaceID/TouchID.
