New Features

Idempotency Key Support: Adds support for the `Idempotency-Key` header in `POST /transactions` to prevent double charges on network failures.
Dark Mode Toggle: Implements a system-wide dark mode based on user preference using Tailwind classes.
2FA with Authenticator App: Adds TOTP support (Google/Microsoft Authenticator) for user login.
Export Transactions to PDF: New endpoint to generate PDF statements for merchants.
Slack Webhooks for Payments: Allows merchants to receive Slack notifications on successful payments.
Biometric Login Support: React Native bridge for FaceID/TouchID.
Suporte a PIX Automático: High demand from Brazilian customers; expected to increase transaction volume by 15%.
Painel de Controle de Fraude: Allows admins to block suspicious IPs manually, reducing chargeback risks.
Integração com Slack: Requested by 3 major enterprise clients for workflow automation.
Suporte a Multi-moeda (USD/EUR): Expands market reach to international merchants.
Login Biométrico Mobile: Improves user retention and login speed on mobile apps.

Fixes

[GitHub PR-460]: Fixes a critical race condition where simultaneous transfers could lock the row indefinitely by applying `SELECT FOR UPDATE SKIP LOCKED`.
[GitHub PR-461]: Corrected decimal rounding on invoice PDF; invoices were showing 10.999 instead of 11.00.
[GitHub PR-465]: Patched SQL Injection vulnerability in the global search bar by sanitizing inputs.
[GitHub PR-466]: Handled null phone numbers in webhook payload to prevent 500 error when phone number is missing in legacy payloads.
[GitHub PR-468]: Fixed crash on startup for iOS 17 by updating the splash screen library.
[GitHub PR-490]: Resolved alignment issue on the Settings page, fixing a 2px misalignment in the submit button.
[Jira JIRA-998]: Resolved 500 error when exporting large CSV files by implementing a streaming response.
[Jira JIRA-1002]: Resolved SQL Injection vulnerability in search by applying parameter binding.
[Jira JIRA-1015]: Fixed app crash on opening in iOS 17 through a library upgrade.
[Jira JIRA-1033]: Resolved duplicate charges during network fluctuations by implementing idempotency logic.
