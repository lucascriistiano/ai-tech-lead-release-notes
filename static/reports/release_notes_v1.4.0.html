Features

New Features

API Enhancements

Idempotency Key Support: Adds support for the Idempotency-Key header in POST /transactions to prevent double charges on network failures.

Dashboard Improvements

Dark Mode Toggle: Implements a system-wide dark mode based on user preference using Tailwind classes.

Authentication Upgrades

2FA with Authenticator App: Adds TOTP support (Google/Microsoft Authenticator) for user login.

Reporting Features

Export Transactions to PDF: New endpoint to generate PDF statements for merchants.

Integrations

Slack Webhooks for Payments: Allows merchants to receive Slack notifications on successful payments.

Mobile Enhancements

Biometric Login Support: React Native bridge for FaceID/TouchID.

Additional Features

Suporte a PIX Automático: High demand from Brazilian customers expected to increase transaction volume by 15%.

Fixes

Database

[GitHub PR-460] Fix Deadlock in Wallet Transfer: Resolves a critical race condition where simultaneous transfers could lock the row indefinitely. Applied SELECT FOR UPDATE SKIP LOCKED.

User Interface

[GitHub PR-461] Correct Decimal Rounding on Invoice PDF: Fixes formatting utility to ensure invoices show correct values.

Security

[GitHub PR-465] Patch SQL Injection Vulnerability in Search: Sanitized inputs on the global search bar. Critical fix.

API

[GitHub PR-466] Handle Null Phone Numbers in Webhook Payload: Prevents 500 error when phone number is missing in legacy payloads.

iOS

[GitHub PR-468] Fix Crash on Startup iOS 17: Updated splash screen library to support newer iOS versions.

General

[Jira JIRA-998] Error 500 When Exporting Large CSV: Implemented streaming response.
