New Features

Bug Fixes

Correção de deadlock no banco de dados durante transferência de carteira: Corrigido condição de corrida crítica onde transferências simultâneas poderiam bloquear a linha indefinidamente. Aplicado SELECT FOR UPDATE SKIP LOCKED.

Risks & Recommendations

The deployment includes critical security patches, a fix for a database deadlock, and breaking changes due to API deprecation and Python upgrade.

  • Monitorar logs de transações do banco de dados para ocorrências de deadlock após a implantação.
  • Verificar se todos os clientes da API migraram de endpoints XML para JSON.
  • Verificar erros de runtime relacionados à atualização para Python 3.11 em instâncias auto-hospedadas.
